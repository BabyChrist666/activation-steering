Core Concepts

Steering Vectors

Directions in activation space that correspond to behavioral traits. Extract from contrastive examples and add during inference.

Contrastive Extraction

Create pairs of positive/negative examples, run through model, compute the mean difference in activations.

Hook System

Flexible hooks for steering, caching, or ablating activations at any layer during forward passes.

Analysis Tools

Measure projection separations, find optimal layers, compare vectors, and quantify steering effectiveness.

Quick Start
